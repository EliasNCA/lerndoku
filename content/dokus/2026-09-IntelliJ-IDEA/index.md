## Ausgangslage

Diesen und letzten Monat habe ich meinen Code mit IntelliJ IDEA geschrieben. Um
bei der Programmierung auf dem Mac effizienter mit IntelliJ IDEA arbeiten zu
können, möchte ich einige wichtige Shortcuts kennenlernen.

<!-- more -->

## Vorgehen

Ich habe nach wichtigen IntelliJ-Shortcuts gesucht und diese direkt ausprobiert.
Dabei habe ich mich vor allem auf Shortcuts konzentriert, welche mir das
Schreiben, Bearbeiten und Navigieren im Code erleichtern.

### Allgemeine IntelliJ IDEA Shortcuts

| Shortcut  | Funktion                  |
| --------- | ------------------------- |
| ⌘ + S     | Datei speichern           |
| ⌘ + Z     | Rückgängig                |
| ⇧ + ⌘ + Z | Wiederholen               |
| ⌘ + C     | Kopieren                  |
| ⌘ + V     | Einfügen                  |
| ⌘ + X     | Ausschneiden              |
| ⌘ + F     | In aktueller Datei suchen |
| ⌘ + R     | Suchen und Ersetzen       |

### Navigation & Code

| Shortcut | Funktion                                          |
| -------- | ------------------------------------------------- |
| ⌘ + P    | Parameter einer Methode anzeigen                  |
| ⌘ + B    | Zur Deklaration bzw. zu den Verwendungen springen |
| ⌥ + F7   | Verwendungen einer Methode oder Variable finden   |
| ⌘ + E    | Zuletzt geöffnete Dateien anzeigen                |
| ⇧ + ⇧    | Überall suchen (Search Everywhere)                |
| ⌘ + 1    | Project-Fenster öffnen/schliessen                 |
| ⌘ + L    | Zu einer bestimmten Zeile springen                |

### Code bearbeiten

| Shortcut      | Funktion                                    |
| ------------- | ------------------------------------------- |
| ⌘ + D         | Aktuelle Zeile duplizieren                  |
| ⌘ + ⌫         | Aktuelle Zeile löschen                      |
| ⌥ + ⇧ + ↑ / ↓ | Zeile nach oben/unten verschieben           |
| ⇧ + ⌘ + ↑ / ↓ | Anweisung/Block nach oben/unten verschieben |
| ⌥ + ⌘ + L     | Code formatieren                            |
| ⌥ + Enter     | Vorschläge und schnelle Lösungen anzeigen   |
| ⌘ + /         | Zeile aus-/einkommentieren                  |
| ⌥ + ⌘ + M     | Code in eine Methode auslagern              |

### Ausführen & Debuggen

| Shortcut | Funktion                                  |
| -------- | ----------------------------------------- |
| ⌃ + R    | Programm ausführen                        |
| ⌃ + D    | Debugging starten                         |
| ⌘ + F8   | Breakpoint setzen/entfernen               |
| F8       | Beim Debuggen zur nächsten Zeile          |
| F7       | Beim Debuggen in eine Methode hineingehen |

## Reflexion

Durch das Kennenlernen der wichtigsten IntelliJ-Shortcuts kann ich beim
Programmieren flüssiger und effizienter arbeiten, da ich seltener die Maus
verwenden muss und mit der Tastatur schneller bin. Die Umstellung auf den Mac
fiel mir leichter als erwartet, weil viele Shortcuts dieselben wie unter Windows
sind und lediglich ⌘ die Rolle von Strg übernimmt, z.B. ⌘ + S statt Strg + S.
Besonders hilfreich finde ich die Tastenkombinationen fürs Bearbeiten von Code,
für die Navigation zwischen Dateien sowie für das Debuggen. Beim Ausprobieren
habe ich darauf geachtet, ähnliche Shortcuts auseinanderzuhalten: ⌥ + ⇧ + ↑ / ↓
verschiebt eine einzelne Zeile, ⇧ + ⌘ + ↑ / ↓ dagegen eine ganze Anweisung. Ich
möchte die Shortcuts weiterhin regelmässig anwenden, damit diese zur Gewohnheit
werden.
