## Ausgangslage

Diesen Monat habe ich begonnen, im Betrieb mit einem MacBook zu arbeiten. Da ich
bisher hauptsächlich Windows verwendet habe, waren mir viele macOS-Shortcuts
noch nicht bekannt. Um mich schneller an das neue Betriebssystem zu gewöhnen,
habe ich die wichtigsten Tastenkombinationen kennengelernt und ausprobiert.

<!-- more -->

## Vorgehen

Ich habe die wichtigsten Tastenkombinationen recherchiert und im Arbeitsalltag
angewendet. Dabei lag der Fokus auf Shortcuts für Fenster und Programme, den
Finder, Screenshots sowie Sonderzeichen für die Programmierung.

### Allgemeine Shortcuts

| Shortcut  | Funktion        |
| --------- | --------------- |
| ⌘ + C     | Kopieren        |
| ⌘ + V     | Einfügen        |
| ⌘ + X     | Ausschneiden    |
| ⌘ + Z     | Rückgängig      |
| ⇧ + ⌘ + Z | Wiederholen     |
| ⌘ + S     | Speichern       |
| ⌘ + A     | Alles auswählen |
| ⌘ + F     | Suchen          |

### Fenster und Programme

| Shortcut  | Funktion                                 |
| --------- | ---------------------------------------- |
| ⌘ + W     | Fenster schliessen                       |
| ⌘ + Q     | Programm beenden                         |
| ⌘ + M     | Fenster minimieren                       |
| ⌘ + Tab   | Zwischen geöffneten Programmen wechseln  |
| ⌘ + `     | Zwischen Fenstern derselben App wechseln |
| ⌃ + ⌘ + F | Vollbildmodus ein-/ausschalten           |

### Finder (Explorer bei Windows)

| Shortcut  | Funktion                            |
| --------- | ----------------------------------- |
| ⌘ + N     | Neues Finder-Fenster                |
| ⇧ + ⌘ + N | Neuer Ordner                        |
| ⇧ + ⌘ + G | Zu Ordner wechseln                  |
| ⌘ + ⌫     | Datei in den Papierkorb verschieben |

### Screenshots

| Shortcut  | Funktion                      |
| --------- | ----------------------------- |
| ⇧ + ⌘ + 3 | Gesamten Bildschirm aufnehmen |
| ⇧ + ⌘ + 4 | Bereich auswählen             |
| ⇧ + ⌘ + 5 | Screenshot-Menü öffnen        |

### Spotlight

| Shortcut      | Funktion               |
| ------------- | ---------------------- |
| ⌘ + Leertaste | Spotlight-Suche öffnen |

### Sonderzeichen für die Programmierung

| Shortcut  | Zeichen |
| --------- | ------- |
| ⌥ + 5     | [       |
| ⌥ + 6     | ]       |
| ⌥ + 8     | {       |
| ⌥ + 9     | }       |
| ⌥ + 7     | \|      |
| ⇧ + ⌥ + 7 | \       |
| ⇧ + 8     | (       |
| ⇧ + 9     | )       |
| ⇧ + ,     | <       |
| ⇧ + .     | _>_     |
| ⌥ + G     | @       |
| ⌥ + N     | ~       |

## Reflexion

Durch das Kennenlernen der wichtigsten macOS-Shortcuts kann ich viele Aufgaben
schneller erledigen. Besonders hilfreich finde ich die Tastenkombinationen für
Fenster und Programme, den Finder sowie die Eingabe von Sonderzeichen für die
Programmierung. Ich möchte die Shortcuts weiterhin regelmässig nutzen, damit sie
zur Gewohnheit werden.
